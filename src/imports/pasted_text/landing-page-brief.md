Crie uma landing page moderna, minimalista, intuitiva, visualmente atraente e totalmente responsiva para uma loja chamada R&CShopping.

A R&CShopping é uma loja de comércio varejista que trabalha com diferentes categorias de produtos, incluindo:

- Roupas
- Moda feminina
- Moda masculina
- Moda infantil
- Cama
- Mesa
- Banho
- Brinquedos
- Utilidades para o lar
- Produtos para presentes

O objetivo principal da landing page é apresentar a loja, destacar os principais produtos e categorias, gerar interesse nos clientes e facilitar o contato, localização e acesso às ofertas.

A página deve transmitir:

MODERNIDADE + CONFIANÇA + VARIEDADE + PREÇO ACESSÍVEL + QUALIDADE

A experiência deve ser simples e intuitiva, permitindo que qualquer cliente encontre rapidamente as informações e produtos que procura.

IMPORTANTE:
- Criar uma interface moderna e atual.
- Utilizar design minimalista.
- Evitar excesso de informações na mesma área.
- Criar boa hierarquia visual.
- Utilizar bastante espaço em branco.
- Destacar informações importantes.
- Evitar conflitos visuais entre textos, imagens e botões.
- Utilizar animações modernas e atraentes, mas sem exageros.
- O design deve parecer profissional e preparado para uma loja moderna.
